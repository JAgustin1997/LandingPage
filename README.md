Versión modificada.
El primer paso fue ingresar a GitHub y crear el repositorio público con el nombre “LandingPage”, después agregué los archivos de la plantilla que utilicé sin modificar y envié el primer commit como “First commit”. En branches creé una nueva rama con el nombre “first_version” para la versión modificada final, y después hice un commit con todas las modificaciones. 
Para mostrar la página fui a settings y en Pages usé la opción “Deploy from branch” y seleccione “first-version” para poder mostrar la página. 

La Landing Page es de turismo asiático. Pienso que es útil gracias al incremento en popularidad de este continente en los últimos años, aparte de poder ser algo más llamativo y único para alguien occidental, a diferencia de otros destinos turísticos más comunes como lo serían países de Europa o América. 

Tuve algunos problemas eligiendo una plantilla que no fuera muy compleja, al igual que mostrando la imagen de fondo en GitHub Pages.
